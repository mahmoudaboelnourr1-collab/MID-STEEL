# MID STEEL — حسابات المصنع (نسخة الـAPK)

الملفات:
- `index.html` — التطبيق كله (ملف واحد).
- `google-apps-script/Code.gs` — سكربت النسخ الاحتياطي على الجيميل والدرايف.
- `icon.png` — أيقونة التطبيق (1024×1024).

> الكود ده اتكتب واتراجع بالفحص النصي بس. ماجربتوش على موبايل فعلي، فجرّبه كويس قبل ما تبعته.

## 1) الحسابات: أدمن واحد ومستخدم

1. على جهازك افتح التطبيق أول مرة → هتظهر شاشة **إنشاء حساب الأدمن**. اعمل حسابك (مرة واحدة بس، بعدها الإنشاء بيقفل).
2. ادخل **الإدارة ← المستخدمين** وضيف المستخدم: اسم دخول وكلمة سر (اكتبها له).
3. افتح تبويب **أوامر التشغيل** ودوس **إرسال ملف المستخدمين وأوامر التشغيل**، وابعت الملف للمستخدم واتساب أو جيميل.
4. المستخدم يفتح الـAPK ← **أنا مستخدم — استلام ملف من الأدمن** ← يختار الملف ← يدخل بالاسم وكلمة السر.
5. أي أمر تشغيل جديد أو مستخدم جديد: ابعت الملف تاني والمستخدم يستلمه.
6. المستخدم يغيّر حالة الأمر بزراير الكارت: استلمت الأمر ← ابدأ التشغيل ← خلص التشغيل ← اتسلم. التغيير بيتحفظ عنده، ولازم يبعتهولك: **إرسال تحديث الحالات للأدمن** (واتساب مثلًا).
7. إنت (الأدمن) في أوامر التشغيل: **استلام تحديث الحالات من المستخدم** واختار الملف، والحالات تتحدّث عندك.
8. لو بعت للمستخدم ملف أوامر جديد قبل ما يبعتلك تحديثاته، تغييراته الأحدث بتفضل زي ما هي.

الملف فيه أوامر التشغيل والحسابات بس، **مفيهوش أي حسابات مالية**. ده اللي بيحميك فعلًا.
الأدمن والمستخدم هنا دور على الجهاز نفسه من غير سيرفر: لو حد عمل حساب أدمن على جهازه هيلاقيه فاضي.

لو نسيت كلمة سر الأدمن مفيش استرجاع. امسح بيانات التطبيق من إعدادات الأندرويد، واعمل حساب جديد، واسترجع آخر نسخة احتياطية.

## 2) النسخ الاحتياطي على الجيميل (أول بأول)

1. روح [script.google.com](https://script.google.com) ← مشروع جديد ← الصق محتوى `Code.gs`.
2. غيّر `KEY` لكلمة سر طويلة من عندك.
3. شغّل دالة `setup` مرة واحدة ووافق على الصلاحيات (Drive وGmail).
4. **Deploy ← New deployment ← Web app**: Execute as = **Me**، Who has access = **Anyone**. انسخ لينك `/exec`.
5. في التطبيق: **الإدارة ← النسخ الاحتياطي** ← الصق اللينك والمفتاح ← حفظ ← **اختبار الاتصال**. لازم يطلع "الاتصال شغال ✓".

بعدها كل تعديل بيتبعت لوحده بعد ٤ ثواني. لو مفيش نت بيستنى لحد ما يرجع.
النسخ بتتحفظ في مجلد `MID STEEL Backups` على الدرايف (آخر ٦٠ نسخة)، ونسخة مرفقة على الجيميل مرة في اليوم.
الاسترجاع: **استرجاع آخر نسخة**.

## 3) بناء الـAPK (Capacitor)

محتاج Node.js وAndroid Studio.

```bash
mkdir midsteel && cd midsteel
npm init -y
npm i @capacitor/core @capacitor/cli @capacitor/android @capacitor/filesystem @capacitor/share @capacitor/assets
npx cap init "MID STEEL" com.midsteel.accounts --web-dir=www
mkdir www assets
cp /path/index.html www/index.html
cp /path/icon.png assets/icon.png
npx cap add android
npx @capacitor/assets generate --android --iconBackgroundColor '#0f2b3d'
npx cap sync
npx cap open android
```

في Android Studio: **Build ← Build APK(s)**. الملف في `android/app/build/outputs/apk/debug/`. ابعته للمستخدم وفعّل له "التثبيت من مصادر غير معروفة".

ملاحظات:
- بلاش تفك التطبيق من الجهاز من غير نسخة احتياطية، لأن البيانات على الجهاز.
- لو عايز الخط يشتغل من غير نت نزّل خط Cairo وحطه في `www/fonts` واعمل له `@font-face`.
- زرارين الحفظ والمشاركة (PDF والصور والملفات) بيستخدموا إضافتي Filesystem وShare اللي في الأوامر فوق.
